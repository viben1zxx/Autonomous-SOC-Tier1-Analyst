# 🛡️ Autonomous SOC Tier-1 Analyst

## 📌 Project Overview
The Autonomous SOC (Security Operations Center) Tier-1 Analyst is an automated cybersecurity triage tool designed to analyze, enrich, and respond to initial security alerts. By automating routine Tier-1 workflows, this project demonstrates how intelligent automation can reduce alert fatigue and accelerate incident response times for enterprise environments.

## ✨ Key Capabilities
* **Automated Threat Triage:** Parses incoming security logs and alerts to identify critical anomalies.
* **Intelligent Enrichment:** Automatically gathers contextual data (e.g., threat intelligence feeds, IP reputation) for flagged events.
* **Incident Prioritization:** Scores and categorizes alerts to efficiently escalate genuine threats.
* **Actionable Reporting:** Generates standardized incident summaries for rapid review.
